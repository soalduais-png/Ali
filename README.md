# نظام مطعمي (Golden Ember Restaurant & Delivery System) 🍔🛵🌐

نظام متكامل لإدارة وتوصيل طلبات المطعم مبني باستخدام **Kotlin** و **Jetpack Compose (Material 3)** وقاعدة بيانات **Room SQLite** مع دعم **العمل أونلاين (Online Server Sync & Live WebSocket Tracking)**، ويضم 3 بوابات مترابطة بنظام دخول موحد:
1. **واجهة العميل (Customer App)**
2. **واجهة مندوب التوصيل (Driver App)**
3. **لوحة تحكم الإدارة والمدير العام (Admin Dashboard)**

---

   - من قائمة الإعدادات يمكنك توليد وتحميل ملف **APK** لتثبيته مباشرة على هاتف الأندرويد.

## ✨ أبرز المميزات المنفذة في النظام

### 1. نظام تسجيل الدخول الموحد والأمان (Unified Auth & Biometrics)
- **التعرف التلقائي على نوع الحساب**: يتم توجيه المستخدم تلقائياً بعد تسجيل الدخول إلى واجهته الخاصة (العميل، المندوب، أو لوحة الإدارة) دون تداخل الصلاحيات.
- **تذكر كلمة المرور وبيانات الدخول**: خيار حفظ اسم المستخدم وكلمة المرور محلياً لتعبئتها تلقائياً عند فتح التطبيق.
- **الدخول بالبصمة (Biometric Login)**: إمكانية تسجيل الدخول السريع ببصمة الإصبع للحساب المحفوظ.
- **إنشاء حساب جديد بحالتين**:
  - **حساب عميل (Customer)**: يتم تفعيله **تلقائياً وفوراً** مع إمكانية إضافة عنوان التوصيل أثناء التسجيل.
  - **حساب مندوب توصيل (Driver)**: يتم إنشاؤه بحالة **بانتظار موافقة وتفعيل الإدارة (`PENDING_APPROVAL`)** ولا يمكنه الدخول إلا بعد تفعيله من لوحة التحكم.

### 2. واجهة العميل (Customer Portal)
- **تصفح المنيو والعروض**: البحث الفوري، فلترة الأصناف، تخصيص الحجم والإضافات، وتطبيق كوبونات الخصم (مثل `FIRST20` و `FREE50`).
- **إدارة عناوين التوصيل**: إضافة، تعديل، وحذف عناوين التوصيل وتعيين العنوان الافتراضي مع حساب المسافة ورسوم التوصيل تلقائياً.
- **الدفع الإلكتروني المتكامل**: دعم الدفع عبر **مدى (Mada)**، **Apple Pay**، **STC Pay**، **Visa / MasterCard**، و**الدفع عند الاستلام (COD)** مع التحقق الفوري وإصدار الرقم المرجعي للعملية (`TXN-...`).
- **التتبع الفعلي المباشر للطلب على الخريطة (Direct Live Order Tracking)**:
  - يتم تتبع الطلبات النشطة مباشرةً على الخريطة التفاعلية دون الحاجة لأي أزرار يدوية، حيث يتحرك موقع المندوب تلقائياً نحو موقع العميل في الوقت الفعلي.
  - بمجرد استلام الطلب أو انتهائه (`DELIVERED` / `CANCELLED`) يتم إغلاق شاشة التتبع وإخفاء الخريطة وزر التواصل مع المندوب تلقائياً.

### 3. واجهة مندوب التوصيل (Driver Portal)
- **استقلالية حساب كل مندوب**: يسجل كل مندوب دخوله بحسابه الخاص دون تداخل مع المناديب الآخرين.
- **إدارة الطلبات المسندة والمتاحة**: قبول الطلبات المتاحة، أو تنفيذ الطلبات المسندة إجبارياً من قِبل الإدارة، وتحديث مراحل التوصيل (`استلام من المطعم` ← `في الطريق للعميل` ← `تأكيد التسليم`).
- **فتح الاتجاهات في خرائط جوجل (Google Maps Navigation)**: زر مباشر لفتح مسار التوجيه الفعلي لموقع العميل عبر تطبيق Google Maps (`google.navigation:q=lat,lng`).
- **المحفظة وكشف العمولات**: متابعة الأرباح اليومية، العمولات المستحقة، والمدفوعات المسددة من الإدارة.

### 4. لوحة تحكم الإدارة (Admin Dashboard)
- **عزل كامل لواجهة الإدارة**: تم إخفاء واجهة العميل وواجهة المندوب من حساب المدير لمنع التداخل.
- **الإسناد التلقائي والإجباري للمناديب**:
  - الطلبات التي يقبلها المندوب يتم تحديده فيها كمندوب مسؤول بشكل تلقائي.
  - الطلبات التي لم يقبلها أي مندوب بعد يمكن للمدير **إسنادها إجبارياً** لأي مندوب متصل ليلتزم بتوصيلها.
- **إدارة المنتجات مع الصور**: إضافة وتعديل المنتجات مع دعم اختيار صورة المنتج من المعرض (Android Photo Picker) أو إدخال رابط صورة أو رمز تعبيري.
- **إدارة بوابات الدفع الإلكتروني**: تفعيل/إيقاف بوابات الدفع وضبط `Merchant ID` و `API Key` و `Secret Key` ووضع الاختبار أو الإنتاج (`SANDBOX` / `PRODUCTION`).
- **إعدادات السيرفر والعمل أونلاين (`إعدادات السيرفر أونلاين 🌐`)**: ضبط رابط `REST API URL` و `WebSocket URL` ومفتاح الربط `API Key` وفحص الاتصال والمزامنة الفورية.
- **عزل الإشعارات لكل مستخدم**: زر الجرس يعرض فقط الإشعارات الخاصة بالمستخدم المسجل دخوله حالياً دون تداخل بين الحسابات.

## 🚀 تشغيل السيرفر أونلاين (Node.js Backend Server)

يوجد داخل مجلد `server/` سورس كود كامل وجاهز للتشغيل لسيرفر المزامنة والتتبع الحي (`REST API` + `WebSocket`):

```bash
cd server
npm install
npm start
```

- يعمل السيرفر افتراضياً على المنفذ `8080`:
  - **REST API Base URL**: `http://localhost:8080/v1`
  - **WebSocket Tracking URL**: `ws://localhost:8080/ws/tracking`
- يمكنك رفع مجلد `server/` على أي استضافة سحابية (مثل Render أو Railway أو Google Cloud Run أو VPS) ووضع الرابط في شاشة **إعدادات السيرفر أونلاين 🌐** داخل التطبيق.
